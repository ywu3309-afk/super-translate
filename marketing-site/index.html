开始之前，你可能想了解

把问题说清楚，再放心使用。

一次性字符包会过期吗？

不会设置固定到期日。¥100、¥200 与 ¥180 套餐均为一次性字符包，字符额度用完为止；本地 AI 与云端翻译共用账号字符额度。

浏览器扩展与桌面端现在可以共用账号吗？

可以。Chrome / Edge 扩展已经上架，使用超级翻译账号和云端字符额度。扩展既保留 WhatsApp Web 专用翻译，也支持用户主动开启的普通网页双语正文、划词和网页已有字幕翻译。前往 Chrome 应用商店 ↗

网页视频都可以实时翻译吗？

当前扩展翻译网页已经提供且浏览器能够读取的字幕，包括部分 HTML5 TextTrack 和页面可见字幕；不会抓取视频音频，也不支持没有字幕的视频实时听译。DRM、跨域 iframe 或 Canvas 自绘字幕可能无法读取。

Android 和 iPhone App 现在可以下载吗？

Android App 已正式开放 v0.3.5 APK 下载；这是首个独立正式签名版本，使用旧 debug 内测版的设备需先卸载旧版再安装一次，后续版本可保持同签名更新。iPhone App 目前暂缓开发。

高级语音版和包月版的语音翻译有限制吗？

高级语音版的客户语音消息转写与翻译不另设时长或次数上限，¥300/月的包月畅用版也包含语音翻译。这里指收到的语音消息，不是 WhatsApp 语音或视频通话同声传译。

每个套餐可以登录多少账号和设备？

每个套餐支持 1 个主账号和 3 个子账号；主账号与每个子账号分别限同时在线 1 台设备，以避免账号之间混用会话和额度。

我的客户数据会在所有设备上同步吗？

统一账号和额度不等于聊天与 CRM 数据已经云同步。现有客户跟进数据以各端当前实现为准，跨设备同步需要独立的数据权限、迁移和冲突处理设计。

下载后如何开通套餐？

下载安装软件不等于自动获得使用权益。以上为初步价格，目前需先注册账号，再由工作人员确认套餐并人工开通；网页暂未接入在线支付或自动开通流程。
