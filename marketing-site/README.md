# 超级翻译官网生产页面

独立静态营销首页，不修改桌面客户端、云端 API、数据库或账号状态。部署时应把现有管理员控制台保留在独立受保护路径，禁止用整站覆盖方式破坏 Node.js 后端。

## 当前产品状态

- Windows 桌面端已发布 `v0.7.38`。
- Android App 已发布独立正式签名的 `v0.3.5`（versionCode 24），公开 APK 与 `update.json` 位于既有 GitHub 更新仓库。
- Chrome / Edge 浏览器扩展正在准备上架；未通过应用商店审核前，不写为已正式上架。
- 套餐已确认一组初步定价，现阶段仅用于网页展示，注册后由管理员人工开通；尚未接入自动支付、订单回调或自动发放权益。
- 每个套餐允许 `1` 个主账号 + 最多 `3` 个子账号；主账号和每个子账号各自仅允许同时在 `1` 台设备上线。

## 预览

在超级翻译源码仓库根目录执行：

```powershell
node marketing-site/serve.cjs
```

浏览器打开 `http://127.0.0.1:4176/`。服务只监听本机；仅提供 index.html、style.css、app.js，不暴露源码仓库其他文件。

## 验证

保持预览服务器运行，在仓库根目录执行：

```powershell
node marketing-site/verify.cjs
```

使用仓库已有 Playwright 与本机 Chrome，检查 1440 / 1024 / 768 / 390 / 360 宽度、横向溢出、FAQ 切换、锚点、错误、无外部请求及下载目标。不实际下载安装软件。

截图与 JSON 报告在仓库 `outputs/marketing-site/`。无付费接口调用、消息发送、登录数据或浏览器个人资料读取。

## 内容边界

- 聊天画面是手工构建的界面示意，不是真实客户截图。
- Windows `v0.7.38` 与 Android `v0.3.5` 均有真实发布产物；官网下载链接、版本号和 Android SHA-256 已在发布时核验。
- Android 标注“正式发布”，浏览器扩展仍标注“上架准备中”；不得把尚未审核通过的扩展写成已正式上架。
- 初步套餐价格已确认，但当前仍是网页展示 + 注册后人工开通；不得虚构自动支付、订单成功或即时发放权益流程。
- 代理合作及尚未实现的产品能力继续明确标注进度，不提供虚假支付或表单。
- 研究与商业方案见 `BUSINESS-AND-PRODUCT-PLAN.md`。
- 页面允许搜索收录；价格仍是初步方案，注册后由工作人员确认开通，暂不直接收款。隐私政策、退款与售后边界必须保持可访问且不得夸大未验收能力。

正式静态部署需要 `index.html`、`style.css`、`app.js` 与 `privacy.html`；线上既有 `register.html`、管理员控制台和 `/api/*` 必须保留。`serve.cjs`、`verify.cjs` 和研究报告不公开上传。
