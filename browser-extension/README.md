# 超级翻译浏览器插件 0.6.0（WhatsApp + 网页双语翻译）

适用于 Chrome / Edge 的翻译插件，使用超级翻译客户账号和云端字符额度。保留 WhatsApp Web 专用联系人/输入框翻译，同时新增用户主动启用的通用网页双语翻译和已有视频字幕翻译。

**0.6.0 为待提交商店审核的更新构建。通用网页/字幕流程使用隔离页面验收；真实客户账号、实际云端扣费和不同视频网站兼容仍需发布前受控实测。请先关闭旧翻译扩展，避免两个版本同时注入。** 隐私政策：https://supertranslation.carseatcoverspace.com/privacy.html

## 安装和登录

1. 把 ZIP 解压到长期保留的文件夹，不要直接打开压缩包中的文件。
2. 打开 Chrome 的扩展程序管理页面，或 Edge 的扩展管理页面，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。
4. 将「超级翻译」固定到工具栏，点击图标打开账号设置。
5. 使用超级翻译**客户账号**登录，不是云端后台管理员账号。插件不需要填写翻译服务 API 密钥。
6. 设置收信、回复目标语言，打开「启用云端翻译」。需要新流程时再打开「发送前自动替换为译文」，点击「保存翻译偏好」。
7. 刷新 WhatsApp Web，点击右侧的「超级翻译」打开工作台。

账号界面可勾选「记住账号」，仅记住账号名称，不保存密码。会话只保存于浏览器本次运行的 session storage；完全退出浏览器后需重新登录。关闭一个窗口但浏览器仍在后台运行，不等同于完全退出。

## 使用原生聊天框自动翻译

1. 在插件账号设置中打开「启用云端翻译」和「发送前自动替换为译文」。后者默认关闭，不会擅自改变旧用户的发送习惯。
2. 选择「跟随当前客户语言」或「使用上方固定回复语言」。
3. 打开 WhatsApp 联系人会话。插件使用 Chrome 的本机语言识别能力，分析该会话最近可见的客户文字；不是根据号码国家推测语言，不额外调用付费翻译服务来识别语言。
4. 如果识别不可靠，可在工作台手动选择对方语言或此联系人的回复语言。简短问候、OK、数字及表情不保证能可靠识别；有历史语言时保留历史结果。
5. 在 WhatsApp 原生聊天框输入任意源语言。打开「实时预览译文」时，停止输入约 400ms 后显示译文；原生聊天框此时保留原文，便于继续编辑。
6. 你按 Enter 或点击 WhatsApp 发送按钮时，插件等待翻译、重新验证云端授权、替换输入框，再触发一次发送。不能确认替换成功时不触发发送。
7. 关闭「实时预览译文」可使用仅发送时翻译模式，减少编辑过程中的翻译请求。

语言偏好按云端客户账号和 WhatsApp 会话标识隔离保存；本地持久化保存的是哈希会话键和语言设置，不保存识别用的聊天原文。对方语言的手动选择用于回复语言偏好，当前云端接收翻译仍由服务自动识别原文。

## 通用网页与已有字幕翻译

1. 先在插件中登录并开启「启用云端翻译」。
2. 打开要阅读的普通 HTTP(S) 网页，再点扩展图标；选择目标语言和「原文 + 译文」或「仅显示译文」。
3. 点击「翻译当前网页」。扩展使用 `activeTab + scripting` 只注入当前顶层页面，不在所有网站后台常驻。
4. 可选「持续翻译动态内容」，用于滚动加载和单页应用；可选「翻译已有视频字幕」，用于页面已经呈现的 YouTube 字幕或浏览器已暴露的 HTML5 TextTrack 字幕。
5. 页面右上角工具条可切换双语/译文、翻译选中文字或停止。插件菜单中的「恢复本页原文」会移除扩展包装和字幕叠层。

隐私与边界：网页翻译会把待翻译的可见文字片段发送到超级翻译云端并按字符扣费；扩展排除表单、密码框、可编辑区、代码、隐藏节点和 iframe，不发送页面 URL、Cookie、整页 HTML、视频文件或音频。为把授权绑定到当前标签页，当前 URL、随机授权值和选项只短暂保存在浏览器 session；导航、停止、关闭标签页、退出或会话结束时清除。短期去重缓存只在页面内存中保留。停止会取消尚未开始的任务；已经提交云端的请求可能已经计费。当前字幕功能要求网页本身已有字幕；**无字幕视频的实时听译尚未支持**。

### 发送保护与额度

- 中文输入法选字回车不会触发译文发送；Shift+Enter 仍用于换行。
- 切换联系人、修改草稿、改变语言或切换登录账号，旧译文不得发出。
- 额度不足、套餐到期、翻译失败、输入框状态异常时，阻止原文自动发送，保留可恢复的草稿。
- 连续按回车或点击发送，不排队重复发送；发送结果未确认时不会自动重发。
- 同一份未修改且仍有效的付费预览可直接发送，不重复请求翻译或扣字符。预览发送凭证有效期 2 分钟、单次使用，发送前仍访问云端验证账号有效性。
- 翻译刚好用完余额时，该次已经成功付费的预览可发送一次；后续新翻译需补充额度。账号到期或停用则不能继续发送预览。
- 修改草稿或预览过期后重新翻译，会产生新的字符消耗。「重新预览」也是付费翻译操作。
- 页面出现新发出的译文消息仅证明 WhatsApp 页面已接受发送操作；是否已送达对方仍以 WhatsApp 消息状态为准。
- 当前自动发送优先从活动会话的选中行、Header 或消息标识确认稳定的 WhatsApp 会话；号码型 Header 会作为安全回退。完全无法确认联系人时不自动发送。

## 保留的手动翻译模式

- 在消息下点击「翻译为…」，查看该条消息的译文。
- 工作台中输入回复，或点击「读取聊天框草稿」。选择语言，点击「生成译文」。
- 关闭「发送前自动替换为译文」时，核对译文后点击「填入草稿」，然后在 WhatsApp 内自行发送。此模式保留旧行为。
- 语言菜单支持中文、英文、本地语言名称与语言代码搜索；Enter 选中匹配项，方向键选择，Escape 或点击外部关闭。
- 「自动翻译客户消息」默认关闭。打开后只自动翻译确认来自客户的可见文字，排除己方消息；重新加载页面可能重新翻译并扣费。
- 「试译一句」也会消耗字符，不是免费演示。
- 额度耗尽、账号停用或套餐到期时无法继续翻译，没有免费引擎兜底。
- 通用网页首版支持普通可见正文、动态内容、划词及网页已有字幕；不包含无字幕视频实时语音识别，也不代表每个 DRM/自绘播放器均已兼容。

## 这次改了什么

- 修复真实 WhatsApp Web DOM 更新后已打开联系人仍被判定为“未打开会话”的问题；支持选中行、裸 JID 与国际号码 Header，并避免把己方消息 ID 或消息预览中的电话号码误当作客户。
- 原生输入框提示与发送链路明确支持任意源语言，不再把功能描述限定为中文输入。
- 使用用户提供的蓝色「文 / A」Logo，生成本地 16 / 32 / 48 / 128 px 图标。
- 登录页、剩余额度卡片、语言菜单、页面悬浮入口、翻译工作台与消息译文统一为蓝白色「超级翻译」样式。
- 删除「清晰翻译」旧品牌、旧引擎选择入口和不适用的上下文选项。
- 复用云端登录、心跳、额度和翻译接口，密钥保留在服务器。
- 登录令牌不传给聊天页面，不写入持久化 local storage；错误响应不回显服务器内部信息。
- 不修改 Electron 应用；保留旧手动模式的 `getEditor`、`chatKey` 和 `fillDraft` 实现，新功能由独立 `auto-compose.js` 在 document_start 安装捕获阶段监听。
- 新增独立的 `web-content.js`、`web-subtitles.js` 和 `web.css`；使用最小化 `activeTab + scripting` 权限，只在用户点击后注入当前网页。
- 网页正文支持双语/仅译文、恢复原文、动态 DOM、滚动加载、划词翻译和页面内存去重；字幕支持可见 YouTube 字幕与 HTML5 TextTrack/DOM 字幕，且不捕获音频。

## 验收范围

- 31 项核心/联系人路由测试：设置白名单、保护标记、请求来源、会话私有性、退出竞态、排队取消、重复在途请求合并、停用、额度不足、语言偏好隔离、单次付费预览凭证，以及 WhatsApp DOM 变化后的当前客户识别等。
- 45 项 Chromium MV3 测试：真实加载扩展，连接本机隔离 HTTPS 模拟账号服务，使用模拟 WhatsApp 文档验证登录界面、语言搜索、预览、填入但不发送、状态清理、Options 页边界和 320/360/420px 界面布局。
- 原生输入框专项测试另验证真实 Chrome 语言检测、收到新消息、400ms 预览、Enter/点击发送、重复操作、输入法、仅发送时翻译、切换会话、编辑竞态、替换失败、发送未确认、到期及零额度。准确数量见 `auto-verification.json`，与基础 UI 用例有重合，不累加宣称独立用例总数。
- 生产云端只做无账号只读连通性检查：健康接口 200，未认证翻译请求 401。未使用真实客户密码或翻译 API 密钥。
- 通用网页专项包含 30 项隔离 Chromium 检查与 9 项后台 capability 安全检查，覆盖显式 activeTab 注入、双语渲染、敏感节点排除、重复文本缓存、动态内容、目标语言切换、原文字节级恢复、重复启动/Service Worker 恢复、nonce 轮换和 WhatsApp 任务优先；独立字幕专项包含 39 项本地合成检查，覆盖 TextTrack、原生字幕复用、叠层避让、模式切换、竞态、nonce、多视频归属、隐藏状态、迟到响应和不控制/捕获媒体。不同测试套件存在链路重叠，不把数字简单相加宣称为完全独立用例。
- 测试截图内的客户、文字和额度均为模拟数据，不代表真实客户或真实余额。

## 发布和授权边界

- 解压加载的扩展不通过桌面端 GitHub 自动更新，需要替换文件夹并在扩展管理页重新加载。商店发布与自动更新需另行配置。
- 不把私有源码推送到桌面端公共二进制发布仓库。浏览器扩展的 JS 本身对安装者可见，混淆不等同于保密；关键收费与授权仍由服务器裁决。
- 当前云端没有令牌撤销接口。「退出」清理本插件会话并停用本插件翻译，不代表撤销其他设备的登录令牌。
- 网络超时不自动重试，避免重复扣费。已提交请求在退出或断网前可能已完成，重试前先刷新额度。云端跨请求幂等仍需独立完善。
- 图标来源：本次用户提供图片。没有从远端加载品牌图片、字体或脚本。
