# Super Translate · Windows Releases

本仓库只提供“超级翻译”的 Windows 安装包与 Electron 自动更新元数据。

- [下载最新版本](https://github.com/ywu3309-afk/super-translate/releases/latest)
- 安装包、`latest.yml` 与对应 `.blockmap` 必须来自同一个 Release。
- 源代码、模型包、测试夹具和开发资料不在此仓库；发布构建由受限的私有源码仓库完成。

如需报告安装或更新问题，请附上软件版本、安装包 SHA-256 和错误信息，不要提交账号、密码、API Key 或本地模型文件。
