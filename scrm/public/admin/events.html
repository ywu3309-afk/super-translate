新手指引 · 广告回传

广告回传就是：访客在你落地页做了动作（点按钮、提交表单），系统自动告诉广告平台“这条广告带来了一次转化”。

  1. 新建回传事件：填事件名、平台、像素 ID 和令牌
  2. 关联落地页/回传地址：地址里可以用 {click_id}
  3. 保存后点「手动回传」发一次测试，确认日志是成功
  4. 把回传链接放进广告后台，之后每次转化会自动记录
